# GoldPet – Final PRD v2.1 (Gamification & Social+)

> 본 문서는 GoldPet 서비스의 **기능, UX, ERD, 인프라**를 종합하고, **게이미피케이션 및 소셜 기능을 강화**하여 고도화한 최종 PRD이다. 이 문서는 향후 모든 기획/개발/운영의 기준(Source of Truth)이 된다.

---

## 0. 제품 비전 & 타깃

### 0.1 제품 비전

> “반려동물과 함께하는 모든 순간을 기록하고, 그 기록을 통해 **좋은 산책 코스와 좋은 사람/펫을 연결**하며, **지속적인 동기를 부여**하는 반려 라이프 플랫폼”

- 산책 중심의 **행동 데이터(위치·시간·궤적)** +
- 펫/사용자 성향 정보 +
- 커뮤니티 & 매칭 기능을 결합하고,
- **게이미피케이션(뱃지/챌린지)** 요소를 통해 사용자의 꾸준한 참여를 유도하여,
- 단순 SNS가 아니라 **실제 만남과 즐거운 산책 경험**까지 연결한다.

### 0.2 타깃 유저

- 반려견/반려묘(및 향후 조류/파충류 등)를 키우는 20~40대
- 산책과 야외 활동을 즐기는 유저
- 반려동물 친구 & 사람 친구를 함께 만들고 싶은 유저
- 귀여운 **AI 펫 프로필 이미지/영상**에 관심이 많은 유저
- 자신의 활동에 대한 **성취감과 보상**을 중요하게 생각하는 유저

## 1. 플랫폼 & 기술 스택

### 1.1 클라이언트

- **Flutter**
  - Target: Android / iOS
  - 지도: **Naver Maps API** + `flutter_naver_map`
  - 상태관리: Riverpod / Bloc (추후 팀 결정)

### 1.2 서버

- **Java 21 + Spring Boot 3.x**
- REST API + Swagger (OpenAPI 3)
- JWT 기반 인증/인가 (Access + Refresh Token)

### 1.3 데이터베이스 & 위치

- DB: **PostgreSQL**
- 확장: **PostGIS**
  - `geometry(Point, 4326)` : 사용자/Spot/장소 위치
  - `geometry(LineString, 4326)` : 산책 궤적
  - GIST 인덱스 기반 공간 쿼리

### 1.4 인프라 & DevOps

- Docker / docker-compose (로컬)
- AWS ECS Fargate (prod/stage)
- AWS RDS for PostgreSQL (PostGIS 활성화)
- Redis (세션/캐시/실시간 기능 보조)
- S3 (파일 저장) + CloudFront(옵션)
- GitHub Actions (CI/CD)
- 모니터링: CloudWatch + APM
- 에러 트래킹: Sentry 등

## 3. 기능 상세 (레벨 2 – 흐름 중심)

### 3.1 ~ 3.2 (회원가입, 프로필 - 기존과 동일)

- SNS 간편가입, 상세 온보딩 플로우, 사용자/펫 프로필 관리 기능은 v2.0과 동일.
- 단, `users` 테이블에 `main_location_geom` (Point 타입)이 추가되어, 위치 설정 시 해당 좌표가 저장되어야 함.

### 3.3 산책 기능 (GPS + 지도 + 앨범)

- **(강화) 장소 체크인:**
  - 산책 중, 지도에 등록된 특정 장소(펫 프렌들리 카페, 공원 등) 근처에 도달하면 '체크인' 버튼 활성화.
  - 체크인 시 `check_ins` 테이블에 기록.
  - 특정 장소 체크인 횟수 등으로 **뱃지 획득** 조건으로 활용 가능.

### 3.4 친구 찾기 & 매칭

- **(강화) 추천 로직:**
  - 단순 거리 외에, **공통으로 방문한 장소(체크인)**, **비슷한 산책 시간대/거리**, **함께 달성한 챌린지** 등을 추천 점수에 반영하여 더 잘 맞는 친구를 상위에 노출.

### 3.11 (신규) 게이미피케이션

#### 3.11.1 뱃지 & 업적 시스템

- **개요:** 사용자의 특정 활동을 기반으로 뱃지를 부여하여 성취감과 재방문 유도.
- **뱃지 종류 (예시):**
  - **산책:** 첫 산책, 누적 거리 100km, 10일 연속 산책, 특정 공원 방문 5회.
  - **소셜:** 첫 친구 매칭, 5명의 친구와 채팅, 커뮤니티 글 10개 작성.
  - **수집:** 펫 3마리 등록, 5종류의 뱃지 수집.
- **화면:**
  - '마이페이지' > '내 뱃지'에서 획득한 뱃지 목록 확인 가능.
  - 대표 뱃지를 프로필에 노출하는 기능.

#### 3.11.2 챌린지 시스템

- **개요:** 기간이 정해진 목표를 제공하고, 달성 시 Gold 또는 특별 뱃지 등 보상 지급.
- **챌린지 종류 (예시):**
  - **주간:** 이번 주에 5일 이상 산책하기, 총 20km 걷기.
  - **월간:** 이번 달에 새로운 친구 3명 만들기.
  - **이벤트:** 특정 기간 동안 지정된 장소 3곳 모두 체크인하기.
- **화면:**
  - '홈' 또는 '산책' 탭에 현재 진행 중인 챌린지 카드 표시.
  - '챌린지' 페이지에서 전체 챌린지 목록 및 내 진행 상황 확인.

### 3.12 (신규) 장소 체크인 & 탐색

- **개요:** 펫과 함께 갈 수 있는 장소(카페, 식당, 공원 등)를 지도에 표시하고, 사용자가 방문 시 '체크인'하여 기록.
- **데이터:**
  - 초기 장소 데이터는 운영자가 `places` 테이블에 등록.
  - 향후 사용자 제보/등록 기능 고려.
- **화면:**
  - '친구 지도' 또는 별도 '장소 지도' 탭에서 장소 마커 표시.
  - 장소 상세 화면: 정보, 사진, 다른 사용자들의 체크인 기록/리뷰 확인.

## 4. 데이터 모델 (ERD v2.1 - 기능 강화안 포함)

> `GoldPet_Final_ERD_PostGIS_v1.0.md`를 기반으로, 신규 기능 수용을 위해 다음 테이블들을 추가/수정한다.

### 4.1 신규 테이블

- **`badges`**: 뱃지 마스터 테이블 (id, code, name, description, image_url)
- **`user_badges`**: 사용자 뱃지 획득 기록 (id, user_id, badge_id, created_at)
- **`challenges`**: 챌린지 마스터 테이블 (id, title, description, goal_type, goal_value, reward_gold, reward_badge_id, start_date, end_date)
- **`user_challenge_progress`**: 사용자 챌린지 진행 상태 (id, user_id, challenge_id, current_value, status)
- **`places`**: 장소 정보 (id, name, category, address, location_geom)
- **`check_ins`**: 장소 체크인 기록 (id, user_id, place_id, created_at)

### 4.2 기존 테이블 수정

- **`community_posts`**:
  - `post_type VARCHAR(20) NOT NULL DEFAULT 'GENERAL'` 컬럼 추가.
  - `adopted_comment_id BIGINT NULL REFERENCES community_comments(id)` 컬럼 추가.

### 4.3 초기 데이터(Seed Data)

- 다음 테이블들은 서비스 시작을 위해 초기 데이터가 필요하며, 별도 Flyway 마이그레이션 스크립트(`V2__Seed_Data.sql`)로 관리한다.
  - `pet_species` (개, 고양이 등)
  - `pet_breeds` (리트리버, 코숏 등)
  - `community_categories` (산책, 건강, 정보 등)
  - `badges` (초기 뱃지 목록)
  - `challenges` (오픈 시점의 챌린지)
  - `places` (초기 장소 목록)
