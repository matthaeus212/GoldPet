# GoldPet – 친구 지도 화면 UX / 와이어프레임 (Naver Map 기반) v1

## 1. 화면 목적 & 진입 경로

### 🎯 화면 목적

친구 지도 화면은 **내 주변 반려인/펫을 “지도 위에서” 직관적으로 찾는 것**이 목표다.

- 내 현재 위치 또는 주요 활동 지역을 중심으로,
- 반경 내 추천 친구/매칭 후보를 **Naver 지도 마커**로 보여주고,
- 마커/카드를 통해 상세 프로필/좋아요/매칭까지 자연스럽게 연결.

### 🔁 진입 경로

1. 하단 탭 “친구 찾기” → 상단 탭/버튼에서 “지도 보기” 선택
2. 또는 별도의 “지도” 탭 (향후 확장 시)
3. 프로필/마이 페이지에서 “근처 친구 보기” 버튼 등을 통해 진입

## 3. 상단 영역 – AppBar

### 구성 요소

- **좌측**: 뒤로가기 아이콘 `←`  
  - 홈/친구 찾기 메인으로 돌아가기
- **타이틀**: `친구 지도` 또는 `근처 친구`
- **우측**: 필터/설정 아이콘
  - `⚙` 또는 `filter` 아이콘
  - 탭 시 상세 필터 모달(종/성별/연령대/펫 성격/매칭 여부 등)

---

## 4. 필터/반경 요약 바

AppBar 바로 아래, 한 줄 정도의 요약 바를 둔다.

```text
┌────────────────────────────────┐
│ [반경 3km] [종: 전체] [정렬: 거리] │
└────────────────────────────────┘
```

- `반경`: 1km / 3km / 5km / 10km 등
- `종`: 전체 / 개 / 고양이 / 그 외
- `정렬`: 거리 / 최근 활동 / 매칭율 등 (초기에는 거리 기준)

각 항목을 탭하면:
- 작은 바텀시트/모달로 선택 UI 표시
- 변경 후 지도가 재쿼리 또는 클라이언트 필터 적용

## 5. 중심 영역 – Naver Map View

### 5.1 지도에서 보여줄 요소

1. **내 위치 마커**
   - 파란 점 또는 “나” 아이콘
   - 중심 기준점으로 인식

2. **친구/후보 마커들**
   - 추천 친구(매칭 후보)들을 지도 위 마커로 표시
   - 마커 아이콘:
     - 사용자 프로필 이미지를 반영한 원형 썸네일
     - 또는 종별 기본 아이콘(개/고양이 등)
   - 선택 상태일 때:
     - 아이콘 크기/색상/테두리 강조

3. **친구 수많을 때의 처리**
   - 같은 위치/건물/근처에 여러 명이 몰릴 수 있으므로:
     - 1차 버전: 간단히 위치를 소폭 랜덤 오프셋
     - 향후: 줌 레벨 낮을 때 클러스터링 마커 적용 고려

4. **지도 상 Floating Buttons**

- 우측 하단에 세로 배치:

```text
○ [내 위치]
○ [반경 변경]
○ [지도 타입]
```

- `[내 위치]`: 현재 GPS 기준으로 카메라 이동
- `[반경 변경]`: 반경 프리셋(1/3/5/10km) 선택 바텀시트
- `[지도 타입]`: 일반/위성/야간 모드 등 전환

---

### 5.2 지도 + BottomSheet 연동 UX

- 특정 마커를 탭하면:
  - 해당 사용자 카드가 BottomSheet 리스트에서 선택/스크롤
- BottomSheet에서 카드 스와이프/탭하면:
  - 지도 카메라가 해당 사용자의 위치로 이동 + 마커 강조

## 6. 하단 – 친구 카드 Bottom Sheet 설계

### 6.1 형태

- **DraggableScrollableSheet** 형태로,  
  - 기본은 약 1/3~1/4 높이에서 카드 한두 개만 보이는 상태
  - 위로 드래그하면 리스트 전체(스크롤) 노출

### 6.2 접힌 상태 (요약 리스트)

```text
┌────────────────────────────────┐
│  근처 친구 5명 · 반경 3km      │
│  ┌──────────────────────────┐  │
│  │ [프로필썸네일] 지오 (1.2km) │ │
│  │  🐶 쿠키 · 활발/친화적      │ │
│  │  [프로필 보기]   [♡ 좋아요] │ │
│  └──────────────────────────┘  │
└────────────────────────────────┘
```

- 상단 한 줄:  
  - 예) `근처 친구 5명 · 반경 3km`
- 바로 아래 첫 번째 카드가 표시되고, 좌우/상하 스크롤 유도

### 6.3 펼친 상태 (전체 리스트)

```text
┌────────────────────────────────┐
│  근처 친구 5명 · 반경 3km      │
├────────────────────────────────┤
│  ┌──────────────────────────┐  │
│  │ [썸네일] 지오 (1.2km)     │ │
│  │  🐶 쿠키 · 3살 · 활발/친화 │ │
│  │  주 활동: 서울 강남구     │ │
│  │  [프로필 보기] [♡ 좋아요] │ │
│  └──────────────────────────┘  │
│  ┌──────────────────────────┐  │
│  │ [썸네일] 민지 (0.8km)     │ │
│  │  🐱 레오 · 2살 · 차분/온순 │ │
│  │  주 활동: 서울 서초구     │ │
│  │  [프로필 보기] [♡ 좋아요] │ │
│  └──────────────────────────┘  │
│  …                           │
└────────────────────────────────┘
```

**친구 카드 구성 요소 예시**

- 프로필 썸네일(사용자 or 대표 펫)
- 닉네임
- 거리 (예: `1.2km`)
- 대표 펫 정보:
  - 종(아이콘) / 이름 / 나이
  - 성격 태그(2~3개)
- 주요 활동 지역 텍스트
- 버튼:
  - “프로필 보기”
  - “♡ 좋아요” (이미 눌렀으면 “♥ 취소”로 전환)

## 7. 상태/인터랙션 플로우

### 7.1 초기 진입 플로우

1. 페이지 진입 시 위치 권한 확인
   - 이미 허용된 경우: 현재 위치 또는 main_location 사용
   - 미허용인 경우: main_location만 기준으로 지도 표시
2. 중심 좌표(`centerLat`, `centerLng`) 결정
3. 서버에 친구/후보 리스트 요청:
   - 예: `GET /api/v1/friends/nearby?lat=..&lng=..&radiusKm=3&species=ALL...`
4. 응답 수신 후:
   - 각 후보를 마커 + 카드 모델로 변환
   - 지도의 카메라 범위/줌 수준 결정
   - BottomSheet에 리스트 표시

### 7.2 마커 탭 → 카드 연동

1. 사용자가 지도에서 특정 마커 탭
2. 해당 `userId` 또는 `candidateId` 기준으로 BottomSheet 리스트에서 해당 카드 찾기
3. 리스트를 해당 카드 위치로 스크롤, 카드에 하이라이트
4. 동시에, BottomSheet가 최소 중간 정도 높이까지 올라오도록 애니메이션

### 7.3 카드 탭/스와이프 → 지도 연동

- 리스트 스크롤 중 특정 카드를 탭하면:
  - 지도 카메라가 해당 사용자 위치로 이동
  - 마커를 강조 표시
- 좌우 스와이프 카드 UI(선택) 사용 시:
  - 현재 선택된 카드 기준으로 지도 중심 이동

### 7.4 좋아요 & 프로필 보기

- **좋아요 버튼**
  - 눌렀을 때:
    - 즉시 UI 상에서 하트 상태 변경
    - 서버에 “좋아요” API 요청
  - 상대가 이미 좋아요를 보낸 상태라면:
    - “매칭 성공” 토스트/다이얼로그 + 채팅방 생성 안내
- **프로필 보기**
  - 해당 친구 상세 프로필 페이지로 네비게이션
  - 프로필 페이지에서 추가 정보 및 이전 산책 앨범 확인 가능

## 9. 향후 확장 포인트

- **라이브 상태 표시**
  - 현재 “온라인”인 사용자/펫을 별도 아이콘/색상으로 표시
- **같이 산책 제안**
  - 카드 내에 “같이 산책 제안하기” 버튼 추가 → 일정/장소 제안 흐름으로 연결
- **이벤트/모임 마커**
  - 친구 뿐 아니라, 특정 산책 모임/이벤트 장소도 마커로 표시
- **커뮤니티 연동**
  - 특정 지역의 인기 코스/게시글을 지도 상에서 함께 표출
